## Overview  
This project analyzes sales data across 6 countries using SQL and Power BI. 

## Tools  
- **SQL**: Merged data from 6 datasets, handled missing values, standardized formats, and performed data exploration  
- **Power BI**: Created calculated measures (e.g., total profit, AOV), built visuals, and designed interactive dashboard  

## Key Metrics  
- Total Sales, Total Profit, Total Discount  
- Total Orders, Average Order Value (AOV)  
- Sales by Country, Category, and Payment Method  
- Monthly & Daily Sales Trends  
- Discounts vs. Profit Scatterplot  
- Geo map of store performance

## Features  
- DAX measures for dynamic KPIs  
- Slicers for country, store, category, and payment filters  
- Interactive visuals: line charts, bar charts, pie charts, map, and scatterplot
